## 📌 Overview

AIDVISOR is an AI-driven career development platform designed to help students and aspiring professionals understand their current career readiness and receive personalized recommendations to improve their profiles.

Unlike traditional resume checkers, AIDVISOR combines multiple signals—including resumes, GitHub activity, skills, and career goals—to generate actionable insights and learning roadmaps.

## 🚀 Getting Started

### Clone the repository

```bash

```

### Navigate into the project

```bash

```

### Install dependencies

```bash

```

### Run the development server

